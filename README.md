# Hi, I'm Deborah 👋🏾

I'm an **Experience Designer** interested in the space between an idea and the moment someone actually has to use it.

I design and build digital products, interfaces and experiences — moving between research, UX, visual design, prototyping and implementation depending on what the thing needs.

My background crosses design and software engineering, so I'm equally happy thinking through a user journey in Figma, prototyping an interaction, or getting into the code to make it work.

## What I'm up to

🌿 Building **Perah Studio** — my independent creative and digital practice.

🧪 Experimenting through **Perah Lab**, where smaller product ideas get designed, built and tested.

✦ Currently building **Remain**, a gentle discipleship habit app centred on returning, consistency and staying close to God.

🌐 My personal corner of the internet lives at **[dearlydebbie.me](https://dearlydebbie.me)**.
